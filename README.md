# Thinking Physics – AI Simulation Creator & Interactive Physics Lab

[![Live Demo](https://img.shields.io/badge/Live%20Demo-thinkingphysics.vercel.app-00FF00?style=for-the-badge)](https://thinkingphysics.vercel.app)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](LICENSE)

**Thinking Physics** is an AI-powered simulation creator and interactive virtual physics laboratory. It transforms natural language prompts into real-time visual science simulations, runnable experiment blueprints, and comprehensive STEM lab guides.

🔗 **Live Application:** [https://thinkingphysics.vercel.app](https://thinkingphysics.vercel.app)

---

## ✨ Features

- ⚛️ **AI Simulation Creator**: Describe any physics scenario (e.g., *"Double pendulum chaos"*, *"Refraction through a prism"*, *"Gravitational orbits"*) and generate an interactive simulation instantly.
- 🎛️ **Interactive Controls & Blueprints**: Real-time adjustable sliders, measurement displays, and dynamic visual canvas powered by p5.js.
- 📚 **Comprehensive Lab Guides**: Structured learning objectives, step-by-step procedures, conceptual inquiries, and quiz checks for students and educators.
- 🎨 **Neo-Brutalist Interface**: High-contrast, responsive visual design built with React, Tailwind CSS, and Lucide icons.
- ⚡ **Multi-Model Support**: Supports Google Gemini and OpenAI models for intelligent code and experiment synthesis.

---

## 🔬 Topics Covered

- **Classical Mechanics**: Projectile motion, pendulums, elastic/inelastic collisions, friction, and gravity.
- **Electromagnetism**: Magnetic fields, circuits, Ohm's law, and electromagnetic induction.
- **Optics & Wave Dynamics**: Wave interference, refraction, diffraction, and Doppler effect.
- **Thermodynamics & Fluid Mechanics**: Buoyancy, ideal gas law, and heat transfer.
- **Quantum Concepts**: Wave-particle duality, energy quantization, and atomic transitions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NandanLakshmamanan/thinking-physics.git
   cd thinking-physics
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env.local` file in the root directory:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
